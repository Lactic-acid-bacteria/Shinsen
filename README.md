# 概要
三国志真戦の単語リストです。Windows/Androidの方は機会があればご使用ください。<br>
気が向いたときに更新します。毎シーズン更新されることはないと思ってください。<br>
(iphoneもGbordが使えればできるかも)
## 記載内容
- 星5武将
- 星4武将
- 星5戦法
- 星4戦法
## 使用方法
1. 
1. 画面の一番右下の、ひらがなの「あ」またはアルファベットの「A」で「右クリック」
2. 「単語の追加」をクリックし、ポップアップの一番下にある、「ユーザー辞書ツール」をクリック
3. 上部の「ツール」を選択し「テキストからの登録」を選択
4. ダウンロードした「Windows_S19_list.txt」を選択
5. 成功すれば単語リストが表示されます。(うまくいかない場合はWindows_S19_list.txtを新しく名前を付けて保存し、文字コードを「UTF-16LE」とかにしてみてください)
